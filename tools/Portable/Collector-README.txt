PRICECHECK COLLECTOR — WINDOWS X64

ЗАПУСК: выберите шаблон с включённым HWID. HTTP-прокси необязателен:
при снятой галочке поля и доступность прокси не проверяются, IPv4/TCP идёт
напрямую к серверам через локальный relay проверки HWID. UDP/raw и IPv6 блокируются.
Без HWID игра не запускается. Индикаторы в Launch подтверждают подмену HWID
и, при включённом прокси, игровой IPv4/TCP через него.
Проверки действуют при входе, смене персонажа и во время работы. Ошибка завершает
клиент и останавливает сбор. Перед обновлением драйвера закройте старые игры.

1. Полностью распакуйте ZIP в отдельную папку. PriceCheck.Collector.exe лежит
   прямо в корне; все остальные файлы находятся в одной папке runtime.
   Запустите EXE и подтвердите стандартный запрос администратора.
   Установка программы, .NET или Python не нужна. Игра устанавливается отдельно.
   Не запускайте EXE внутри ZIP; при переносе сохраняйте папку runtime рядом.

2. Collector включает тот же запуск с HWID/прокси, что и Launcher, плюс сбор
   рынка, брокер и проверку цен. Отдельно запускать Launcher на этом ПК не нужно.
   Настройте профиль, путь игры, шаблон и адрес API в настройках сбора.
   Сервер PriceCheck устанавливается отдельно; текущий адрес по умолчанию:
   https://pog-sandbox.com/api. В этом ZIP нет сайта, сервера или его базы.
   Автовход проверен только для Gamma; рынок должен совпадать с сервером входа.

3. Настройки и история: %LOCALAPPDATA%\PriceCheckCollector.
   При переносе профилей и HWID копируйте profiles.json и launch-templates.json
   при закрытом Collector. ID и seed сохраняются. Пароли DPAPI на другом ПК
   нужно ввести заново. Сохранённый центр Гирана сохраняйте без изменения.
   Настройки Launcher лежат отдельно в %LOCALAPPDATA%\PriceCheckLauncher.
   Не собирайте один рынок одновременно с нескольких ПК без координации.

4. Сначала запустите клиент, затем включите сбор для нужного профиля.
   Один PID принадлежит одному профилю. При штатном закрытии Collector
   завершает работу сборщика и останавливает запущенные им игры и прокси.
   Для обновления закройте программу и распакуйте новый ZIP в новую папку.
   Профили, центр, локальная история и outbox в LocalAppData сохранятся.

Включены Windows x64 .NET/WPF, native-agent, автовход, драйвер с loader,
BrokerWorker и Python. runtime\Verify-Package.ps1 проверяет SHA256 всех файлов,
совместим с PowerShell 5.1. runtime\Start-WithDiagnostics.ps1 — диагностический запуск.
Чистая Windows VM не проверена: возможности загрузки драйвера зависят от ОС.
