PRICECHECK LAUNCHER — WINDOWS X64

1. Полностью распакуйте ZIP в отдельную папку. PriceCheck.Launcher.exe лежит
   прямо в корне; все остальные файлы находятся в одной папке runtime.
   Запустите EXE и подтвердите стандартный запрос администратора.
   Установка программы, .NET или Python не нужна. Игра устанавливается отдельно.
   Не запускайте EXE внутри ZIP; при переносе сохраняйте папку runtime рядом.

2. Укажите исполняемый файл игры. В HWID / ПРОКСИ создайте шаблон,
   включите HWID, сохраните и выберите шаблон. HTTP-прокси необязателен:
   при снятой галочке его поля и доступность не проверяются, IPv4/TCP идёт
   напрямую к серверам через локальный relay проверки HWID.
   Индикаторы в Launch подтверждают применение
   HWID и, при включённом прокси, маршрутизацию игровых IPv4/TCP через него.
   UDP/raw и IPv6 блокируются. Проверки продолжаются при входе, смене персонажа и работе;
   ошибка останавливает клиент. После обновления драйвера закройте старые игры.
   Launcher не собирает рынок и не подключается к серверу PriceCheck.
   Автовход проверен для Gamma. Несколько профилей Gamma поддерживаются;
   каждый запускает свой клиент. Ротация использует список персонажей автовхода.

3. Настройки: %LOCALAPPDATA%\PriceCheckLauncher\profiles.json и
   launch-templates.json. При переносе прежних настроек копируйте оба файла
   только при закрытых приложениях. ID профилей, ID шаблонов и seed HWID
   сохраняются; пароли DPAPI на другом компьютере нужно ввести заново.
   Настройки Collector лежат отдельно в %LOCALAPPDATA%\PriceCheckCollector.

4. При обновлении закройте Launcher штатно: это остановит запущенные им игры
   и прокси. Распакуйте новый архив в новую папку и запустите новый EXE.
   LocalAppData сохраняется. Сборщик и BrokerWorker в этот архив не входят.

Включены Windows x64 .NET/WPF, native-agent, модуль автовхода и драйвер с loader.
Драйвер нужен текущей реализации world identity; это не пакет без драйвера.
runtime\Verify-Package.ps1 проверяет SHA256 всех файлов; совместим с PowerShell 5.1.
Чистая Windows VM не проверена: возможности загрузки драйвера зависят от ОС.
