PriceCheck Collector — проверка на другом физическом ПК

1. Распакуйте ZIP целиком в отдельную папку с правом записи, например
   C:\PriceCheckTest. Не запускайте EXE прямо из архива. Клиент LU4 установите
   отдельно; он в архив не входит. Сборка Collector предназначена для
   Windows x64; .NET и Python для самого приложения уже входят в поставку.

2. Перед первым запуском закройте LU4 на этом ПК. Запустите
   Start-WithDiagnostics.ps1 через «Выполнить с помощью PowerShell» и
   подтвердите UAC. Collector подготовит драйвер до запуска игр. Скрипт
   проверяет контрольные суммы и включает существующие журналы метаданных.
   Для обычного запуска есть PriceCheck.Collector.exe.

3. В разделе Launch → Templates создайте два шаблона с разными именами. В каждом
   включите HWID, один раз нажмите Regenerate, оставьте генерацию при каждом
   запуске выключенной и нажмите Save templates. Новые значения сохранятся
   для сопоставимых одиночных и парных запусков. Если нужен прокси, введите
   его отдельно в каждом используемом шаблоне и сохраните.

4. Создайте два профиля с разными именами (например Gamma и Black), выберите
   папки клиента LU4 и назначьте каждому его шаблон. Для обоих укажите сервер
   Gamma; имя профиля Black само по себе не задаёт сервер. Введите разные
   аккаунты и выберите первый слот персонажа, если персонажи уже созданы там.
   Настройте автовход или войдите вручную. Запускайте игры через Launch client
   соответствующего профиля в Collector.

   В этой версии два независимых модуля в одном окне. Launch запускает игру,
   применяет шаблон и поддерживает прокси; радар при запуске не подключается.
   В Collection нажмите Connect reader для выбранного профиля. Можно также
   выбрать уже запущенный клиент для непривязанного профиля через Refresh list.
   Затем задайте центр и включите Start collection. Disconnect reader завершает
   текущее задание, отключает чтение и оставляет игру с прокси работающими.
   Если задание не завершилось за две минуты, повторите отключение позже.
   Закрытие всего Collector останавливает запущенные им игры и их прокси.

   Радар получает события после подключения. Для полного начального обзора
   подключите его перед ручным входом в мир либо дождитесь обновления сцены.
   Одна поздняя привязка не восстанавливает ранее полученные пакеты.
   Разделение модулей проверено сборкой и подставными сеансами; новая версия
   пока не прошла одиночный и парный контроль на реальных клиентах.

5. Сначала проверьте первый профиль отдельно, затем второй отдельно: вход
   в Gamma и минимум 10 минут связи. Закройте игры между этими контролями.
   Затем запустите первый, дождитесь мира и запустите второй в ту же Gamma.
   Оставьте пару на несколько часов. Между контролями сохраняйте те же
   шаблоны, аккаунты, прокси и версию игры. Запишите время входа, длительность,
   ручные выходы и любые сообщения ошибки. Живое окно само по себе не
   доказывает, что соединение с миром сохранилось.

6. Если используете те же аккаунты, которые ещё находятся в игре на первом
   ПК, сначала завершите их сеансы там или используйте другие аккаунты.
   Одновременный повторный вход одного аккаунта сделает сравнение неоднозначным.

7. После опыта, особенно сразу после ошибки, запустите Collect-Diagnostics.ps1.
   Архив появится в %LOCALAPPDATA%\PriceCheckCollector\support; точный путь
   будет выведен в PowerShell. Он содержит выбранные журналы метаданных и
   версии среды, без профилей, паролей, дампов памяти и сырых пакетов.
   Сохраните также текст ошибки и время её появления.

Настройки хранятся в %LOCALAPPDATA%\PriceCheckCollector. На ПК с уже имеющимися
настройками они сохраняются; архив их не заменяет. Пароли Windows DPAPI другого
пользователя/ПК не переносимы простым копированием: введите их на новом ПК.
В поставке нет локальных профилей, аккаунтов, прокси, накопленной базы или игры.

Если Collector сообщает «Could not load LU4Memory», сохраните сообщение и
driver-bootstrap.log через Collect-Diagnostics.ps1. Совместимость загрузки
драйвера с настройками защиты и версией Windows второго ПК ещё не проверена.
Неудача загрузки драйвера — отдельный результат, не отказ сервера Gamma.

Ограничения диагностики: proxy-tcp фиксирует время и длину порций TCP, а не
содержимое пакетов. Native IOCTL trace ограничен 4096 событиями; после лимита
он не доказывает отсутствия новых проверок. Версия клиента/античита должна
соответствовать проверенной сборке; guards при несовпадении могут отказать.

package-manifest.json содержит SHA-256 файлов. Verify-Package.ps1 повторно
проверяет их без запуска игры, Collector или драйвера. Архив подготовлен и
проверен на исходном ПК; результат запуска на втором ПК пока неизвестен.
