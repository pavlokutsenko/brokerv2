## Проверки HWID / прокси — текущая задача

запуском. Полный shared launch прошёл Gamma/world для двух персонажей: первый
с reader до входа, второй без reader до входа. Windows API hooks, фактическая
подмена world handshake, двусторонний прокси-трафик и повторные проверки
подтверждены. Отзыв маршрута остановил игру и запретил следующий вход.
Пользовательские настройки не изменялись; секреты остаются вне репозитория.

Первые live-попытки закрывались после начала входа. Точная причина этих
закрытий не доказана; после поэтапной проверки и восстановления обычного
agent DLL полный запуск проходит. Не приписывать исправление какому-либо
одному снятому барьеру. Подробности и ссылки на журналы:
[launch-protection/RESUME.md](analysis/launch-protection/RESUME.md).
