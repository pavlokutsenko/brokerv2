## Проверки HWID / прокси — текущая задача

HTTP-прокси теперь необязателен. При ProxyEnabled=false его поля, preflight
пропускаются; локальный relay идёт напрямую
к исходному IPv4 серверу, сохраняя контроль HWID/world generation и PID ownership.
UDP/raw и IPv6 всё ещё запрещены. Native MMF lease требует flags 1 (HWID)
или 3 (HWID+прокси). Невключённый прокси показывается нейтральным индикатором,
чужая ошибка больше не выдаётся за обнаруженное несовпадение HWID.

На пользовательском Launcher из архива воспроизведена остановка игры из-за
таймаута отдельного периодического CONNECT. Эти пробы убраны для обоих
режимов; preflight, авторизация реальных игровых CONNECT, непрерывный контроль
HWID/маршрута/ошибок туннелей сохранены. Подробности текущего длительного
прогона: [launcher-soak/RESUME.md](analysis/launcher-soak/RESUME.md).

Текущая сборка прошла два полных live-прогона: без прокси и с тестовым прокси,
в каждом слоты 0/1 через Collector/Launcher flow, непрерывный монитор и
отзыв своего relay с остановкой клиента. HWID E333C54BA1BC из сохранённого
шаблона подтвердился в обоих режимах. Настройки пользователя не менялись.

Новые проверки добавлены по одной после воспроизводимого сравнения с прежним
запуском. Полный shared launch прошёл Gamma/world для двух персонажей: первый

подмена world handshake, двусторонний прокси-трафик и повторные проверки
подтверждены. Отзыв маршрута остановил игру и запретил следующий вход.
Пользовательские настройки не изменялись; секреты остаются вне репозитория.
