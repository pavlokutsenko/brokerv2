# Запуск Launcher и Collector на Windows

В C:\broker находятся два клиентских приложения. Сервер и сайт из
C:\PriceCheck развиваются и запускаются отдельно. В клиентских архивах нет
Node, PostgreSQL, серверного installer, миграций или серверной базы.

1. Скачайте нужный ZIP: Launcher для игровых окон с HWID/прокси или
   Collector для запуска и сбора рынка. Collector уже включает запуск.
2. Полностью распакуйте архив в отдельную папку. EXE лежит сразу в корне:
   PriceCheck.Launcher.exe либо PriceCheck.Collector.exe.
3. Запустите EXE и подтвердите обычный запрос UAC. Игра устанавливается
   отдельно; .NET/WPF, native-компоненты и loader уже включены.
4. Укажите путь игры, создайте и сохраните HWID/прокси-шаблон, выберите его
   в профиле. **Включите обе опции: HWID и авторизованный HTTP-прокси.**
   Без них и при ошибке проверки игра не запускается. Индикаторы Launch
   показывают применение HWID и защиту трафика; проверка продолжается при входе
   персонажа и работе. [Проверки и ошибки](LAUNCH_PROTECTION.md).
5. В Collector укажите URL существующего API PriceCheck в настройках сбора.
   Текущий default: https://pog-sandbox.com/api. Запустите клиент и включите сбор.

Launcher хранит настройки в %LOCALAPPDATA%\PriceCheckLauncher;
Collector сохраняет прежний %LOCALAPPDATA%\PriceCheckCollector.
Для переноса копируйте profiles.json и launch-templates.json при закрытых
программах, сохраняя ID и world seed. На другом ПК пароли нужно ввести
заново: DPAPI связан с исходной учётной записью/компьютером. Сохранённый
центр Гирана не изменяйте; локальная история и outbox принадлежат Collector.

Для обновления штатно закройте приложение: оно завершит работу своих игр
и прокси. Распакуйте новый ZIP в новую папку и запустите новый EXE.
Настройки в LocalAppData сохраняются. Verify-Package.ps1 проверяет размер и
SHA256 файлов; работает в штатном Windows PowerShell 5.1.
При первом обновлении на строгую защиту закройте старые игровые процессы:
bootstrap должен обновить LU4Memory; старый драйвер не принимается.

Текущая реализация world identity требует LU4Memory; драйвер и loader
включены в обе поставки. Чистая Windows VM здесь недоступна: её загрузка
драйвера и реальный запуск на другом ПК ещё не проверены.
Подробности сборки и готовые архивы: [DESKTOP_PACKAGES.md](DESKTOP_PACKAGES.md).
Состав репозитория: [REPOSITORY_LAYOUT.md](REPOSITORY_LAYOUT.md).
