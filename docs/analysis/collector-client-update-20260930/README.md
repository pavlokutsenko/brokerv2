## Исправление обработки сетевого обрыва

Установленный CONNECT-туннель закрывает и дожидается обоих насосов.
IOException/SocketException сохраняются как сетевой диагностический результат,
а не как ошибка проверки защиты всего клиента. Диагностика содержит порт,
тип исключения, HRESULT и SocketError; пароли, HTTP заголовки и пакеты не пишутся.

Статус игрового соединения берётся из активных world-туннелей, когда такой
туннель уже был установлен. Поэтому другие открытые TCP-сокеты не скрывают
от автовосстановления потерю игрового соединения. Для устойчивого разрыва
сохраняется существующий grace period; восстановление сохраняет профиль,
аккаунт, персонажа и намерение читать/собирать. Отключённому клиенту не
передаётся ход и не запускается предварительный расчёт его маршрута.

Ошибки проверки драйверного маршрута, native heartbeat и идентификаторов
по-прежнему обрабатываются как ошибки защиты. Ошибка входа во время уже
запущенного восстановления сохраняет существующий retry/backoff.

Также `--collect-profile` теперь открывает вкладку «Сбор» выбранного профиля:
предыдущий индекс открывал общую вкладку «Шаблоны».
