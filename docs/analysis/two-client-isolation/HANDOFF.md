## Рабочая реализация

В запросе мира путь clmods64/active64 расширяет 37 байт до 69. Точная
эмуляция driver helper воспроизвела все 69 байт одиночных и парных снимков.
Добавленные 32 байта происходят из общего encrypted envelope; средние
16 байт заменены в копии исходящего запроса. Kernel globals/records и другие
процессы не меняются. Версия драйвера, код, layout и integrity проверяются.

Первоначально replacement зависел только от ID профиля. Поэтому Regenerate
20 полей шаблона оставлял его прежним. Теперь `LaunchIdentity.WorldIdentitySeed`
генерируется и сохраняется вместе с HWID. `WorldIdentityConfiguration`
получает 16 байт из SHA-256(profile GUID bytes + seed). Это даёт:

- Regenerate обновляет все 20 поддерживаемых HWID и world identity.
- Режим нового HWID при каждом запуске тоже обновляет seed.
- Фиксированный шаблон сохраняет значения между запусками.
- Общий шаблон даёт разные значения двум профилям.
- ID самого профиля сохраняется как долговременный ключ конфигурации.
- Старые шаблоны без seed сохраняют прежнее значение до регенерации.

Штатные файлы: `native/ClientLaunch/world_identity.cpp`,
`world_send_probe.cpp`, `Services/WorldIdentityConfiguration.cs`,
`ClientLaunchConfiguration.cs`, `Models/LaunchTemplate.cs` и копирование
шаблонов в `LaunchTemplatesView.xaml.cs`. UI новых платформ/пакетов не требует.
Состояние агента: LocalAppData `logs/world-identity-<PID>.txt`.

## Что отправляется после входа

После начальных сообщений идут 27-байтовые отправки примерно раз в 30 секунд.
До и после перехвата античита размер равен 27; каждый вызов соответствует
успешному IOCTL 0x222160. Входящие мировые данные проходят через 0x22215C.
В этих контролях поздний EOF не возник, дополнительная подмена не применялась.

Три read-only periodic snapshots точно воспроизводят изменение RC4 state
для 25-байтового тела и шаг XOR counter +25. После обратных преобразований
byte 2 равен 0x03. DWORD по offset 3 увеличился на 300562 за 300559.6 мс:
это свидетельство в пользу счётчика времени, но не установленная спецификация.
Исходный middle16 и replacement16 не найдены как непрерывная последовательность.
Полная эмуляция periodic helper пока не завершена: unmapped read RVA 0x1354D3.
Не считать это доказательством отсутствия производных HWID в поздних сообщениях.

## Версии, проверки и ограничения

Аудит по вопросу пользователя об обновлениях: автоматической адаптации ко
всем изменённым оффсетам нет. Частичные version/signature guards не образуют
единую проверку совместимости всех модулей; изменение самого пути отправки
может обойти распознавание запроса world identity. Не обещать, что новая
сборка только выдаст контролируемую ошибку. См.
[границы совместимости](observations/2026-09-24-update-compatibility.md).

- Root `build.ps1 -SkipBroker` успешно опубликовал release.
- Resolver checks: стабильность, разные профили, регенерация, legacy, invalid seed.
- Template UI smoke: seed переживает копирование и сохранение.
- `git diff --check` чист; предоставленных учётных данных в текстах repo нет.
- Agent SHA-256: `457D621DF542FB07CACC8E02856EF28BBB835A9864A422B3785461057A899E95`.
- Collector DLL SHA-256: `34EE87006E5F34F0265582FBBBB8AC82B07E478DAADDDFA31ACE58399EDB3467`.

`LU4Memory` и `PRProt` уже работали; драйвер не перезагружался, `LU4Probe`
не загружался. Новых live memory writes/хуков для periodic snapshots не было.
Штатный radar hook остаётся частью существующего Collector.

Проверено десять минут работы пары, а не неограниченная устойчивость или
полная изоляция Windows. Причина прежнего позднего разрыва и серверный код
отказа не установлены. Регенерированы одновременно 20 HWID и world seed,
поэтому этот новый опыт отдельно не определяет, какое из полей сняло ранний
отказ. Проверка без прокси в этом продолжении не выполнялась.

Новые приватные снимки, scripts и encrypted backups находятся только в
LocalAppData `research/late-world-disconnect/`; backup settings — подпапка
`20260924-115359`. Не восстанавливать аккаунты/прокси целиком без запроса.
Старый binary backup до первого исправления — `research/builder-source/
release-backup-20260924-113411`. Не заменять DLL при запущенных клиентах.
Рабочее дерево было сильно изменено до задачи; не откатывать его целиком.

При новом разрыве сначала сохранить TCP/IOCTL timeline, проверить живую
связь и сообщение ошибки. Не делать вывод по координатам или существованию
окна. Новую гипотезу проверять одиночным и парным контролем, не повторять
прежние исключённые подмены. После обновления игры заново проверить guards.
