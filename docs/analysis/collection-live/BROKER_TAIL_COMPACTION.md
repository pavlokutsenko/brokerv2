The collector now replaces a queued suffix of broker-only operations for one `traderKey` when a newer **complete** broker observation arrives from the same source profile. The replacement is atomic with insertion of the newer durable operation. It never crosses a pending state or price operation, an operation already being sent, a different source profile, or a broker observation newer than the replacement. Incomplete observations do not trigger compaction. The latest complete inventory carries the current item quantities and listing composition, so the superseded unsent broker-only observations have no remaining effect.
