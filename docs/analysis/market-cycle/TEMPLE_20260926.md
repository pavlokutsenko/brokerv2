## Publication durability

build.ps1 publishes to a fresh staging directory. publish-durable.ps1 validates
the runtime config, rejects zero-filled important files, writes an immutable
recovery version using WriteThrough/Flush(true), then atomically commits a
manifest before atomically replacing installed files. An interrupted installation
can be completed from that committed version. start-collector.ps1 verifies/restores
all hashes before launching. Existing .NET config/outbox atomic recovery remains.

PackageRecovery.Smoke.ps1 passed under Windows PowerShell: recovery of a zeroed
installed runtime config, restoration of a mixed version installation, and rejection
of a damaged source without changing the committed installation. This protects
against the observed cache/partial-write failure; it cannot guarantee recovery
from physical disk corruption affecting both installation and recovery copies.

## City boundaries

maps/cities.json selects a city's descriptor under maps/<City>/city.json.
Giran's geometry, captures and reports now live under maps/Giran. Origin and
temple exceptions are selected from that descriptor, never applied to another
city by default. Unknown/unvalidated cities are rejected before game bridge
installation. Future cities require their own geometry and live validation.
