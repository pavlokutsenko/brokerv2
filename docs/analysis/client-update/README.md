# Обновление клиента LU4 — 28 сентября 2026

Старая проверка точных PE timestamp/SizeOfImage останавливала запуск после
обновления игры. В рабочем пути убраны фиксированные RVA GObjects, GWorld,
envelope active64 и источника world handshake. Нативный login ищет таблицы
GObjects/FNamePool в памяти загруженного клиента, проверяет их структуру и
находит нужные отражённые функции по имени и владельцу. World identity
находится в доступной для записи секции active64 с проверкой keyed digest.
Reader ищет указатель мира по цепочке world/player/capsule/coordinates.
Смещения полей и слот ProcessEvent остаются структурным ABI и проверяются
на живом процессе; при несовместимости программа завершает запуск с ошибкой.

На обновлённом локальном клиенте прошёл реальный Launcher: персонаж вошёл
в мир, позиция подтверждена чтением GWorld, HWID API/world и маршрут прокси
были активны. Один и тот же игровой PID оставался подключённым и отзывчивым
217 секунд, через выбранный сохранённый прокси прошло 6 игровых CONNECT.
После добавления поиска envelope повторный LiveSmoke с сохранённым прокси
тоже вошёл в мир и подтвердил двусторонний world-трафик. Пользовательские
шаблоны и секреты не изменялись.

Ограничения проверки: реальный Launcher запускался с временной подстановкой
другого сохранённого Gamma аккаунта только в памяти тестового процесса;
учётные данные третьего профиля не подтверждены этим прогоном. Ротация
персонажей на этом клиенте пока не проходит: MinHook возвращает
`MH_ERROR_MEMORY_PROTECT` при включении roster ProcessEvent hook. Вход в
мир проверен с отключённой ротацией. На другом ПК и на чистой Windows
переносимую сборку нужно проверить отдельно.
