# Resume

Strongest finding: a live HardShift launch mapped `C:\D\HardShift\assets\HsAgent64.dll` into protected `lu4.bin` without placing `version.dll` beside the game. Its log records per-PID profile application and SMBIOS patching through a manually mapped kernel driver. Static disassembly found a separate injection IOCTL (`0x222140`) that passes a PID and two DLL paths, but the exact kernel execution primitive is still unknown. The collector currently has an independent agent loaded through `version.dll`; a local smoke test passed identity and HTTP CONNECT authentication.

Live collector launch validation reached the login screen for HWID-only and authenticated HTTP-proxy modes; both installed the collector receive-hook in the final `lu4.bin`. Reusable launch templates now own 20 identity values and optional HTTP-proxy settings; old per-profile settings migrate automatically. A candidate LU4Memory IOCTL that only opened a target-process handle failed under Active Anticheat (`GrantedAccess=0x1400`) and was removed. The verified driver and working `version.dll` launcher were restored. See `README.md`, `../driver-agent-load/PROGRESS.md`, and `FAILURES.md` for evidence and limits.
