# Gamma: два аккаунта, автоматический скан и подтверждение HWID

2026-09-30, 11:05:29 Europe/Kiev. Проверка прошла на обычном приложении
`release/PriceCheckCollector/PriceCheck.Collector.exe`, Collector PID 1560.
Кнопка «Сканировать ПК» удалена из общих шаблонов Launcher и Collector.
Автоскан при открытии вкладки и перед каждым запуском сохранён; раскрытый
список теперь не сворачивается при очередном автоматическом обновлении.

Первый запуск с тремя сохранёнными аккаунтами остановился на первом аккаунте
без прокси: подтверждение HWID прошло, но экран выбора персонажа не появился
до таймаута. Проверка всех трёх тогда не состоялась. Пользователь затем оставил
два аккаунта с двумя разными сохранёнными шаблонами и попросил проверить их.
Профили, пароли и шаблоны для обхода этого результата не подменялись.

## Повторный запуск с двумя аккаунтами

Обычный startup аргумент `--launch-accounts=Gamma` запустил текущий сохранённый
состав профиля. Оба аккаунта используют прокси, указанные в своих шаблонах.
Первый клиент подтвердил launcher ready в 11:03:14, второй — в 11:03:58.
Коллектор и оба клиента оставлены работающими; сбор цен отдельно не запускался.

| Персонаж | PID | Тег идентификатора | Подтверждение |
| --- | ---: | --- | --- |
| Wics | 16300 | EF2A07111049 | HardwareReady, WorldIdentityApplied, ProxyReady, reader connected |
| Uce | 4368 | 65A883CB8F78 | HardwareReady, WorldIdentityApplied, ProxyReady, reader connected |

Тестовый наблюдатель внутри реального приложения подтвердил 61,27 секунды
непрерывной одновременной готовности двух процессов. Для обоих: flags=7,
native error=0, совпадают PID и время создания, tag соответствует аккаунту и
выбранному шаблону, применённые world bytes совпадают с ожидаемыми. Возраст
agent heartbeat на итоговом снимке — 141 и 234 мс. Оба окна отвечают, TCP
соединения активны, fatal window отсутствует. Теги различаются.

Обычный native HWID readback проверяет через public API SMBIOS UUID,
MachineGuid, серийный номер тома и MAC. Подтверждение игрового мира дополнительно
сверяет заменённые байты текущего world-подключения и подтверждённый обмен.
Native hardware trace фиксирует повторные firmware/registry/adapter проверки
и одно world_identity_applied для каждого PID.

## Границы результата

Используется прежний проверенный драйвер: identity-driver.log для обоих запусков
содержит kernel=False. Новая системная registry-подмена не включена и этой
проверкой не подтверждается. Подтверждение агента и world-подключения не
доказывает покрытие каждого запроса античита или всех альтернативных API.
Полная таблица: [Hardware identity](../../HARDWARE_IDENTITY.md).

Наблюдатель [CollectorIdentity.LiveProbe](../../../tests/CollectorIdentity.LiveProbe/README.md)
читает runtime/lease и состояние окон. Он не заменяет методы запуска/входа,
не отключает проверки, не меняет credentials и не входит в дистрибутив.

Проверки: build.ps1 -SkipPackages, Launcher.Smoke с автосканом и
CollectorIdentity.LiveProbe build прошли. Данные итогового PASS:
`workspace/identity-gamma-two-live-20260930/verified.json`; исходный журнал и
снимок приложения — `observer.log` и `observer.png` в той же папке.
