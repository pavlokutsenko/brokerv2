# Состав репозитория

Этот репозиторий содержит клиентские приложения Launcher и Collector.
Сервер, сайт и серверная база развиваются отдельно в C:\PriceCheck.

| Каталог | Что хранится |
| --- | --- |
| src | Две WPF-оболочки, общий запуск/UI, сборщик, contracts и Windows transport |
| native | Исходники native-agent/автовхода и проверенного драйвера |
| maps | Утверждённая геометрия и навигация Гирана, исходные данные для её воспроизведения |
| tools | BrokerWorker, игровой протокол/навигация, outbox sender и файлы портативных поставок |
| scripts | Сборка ZIP, durable-публикация и локальный цикл разработки |
| tests | Клиентские проверки и тесты целостности ZIP |
| docs | Архитектура, запуск и технические результаты исследования |

Старая локальная серверная поставка удалена: InstallerHost, PostgreSQL/Node
packager, Setup/серверный installer и одноразовые миграционные/cutover-скрипты.
Сборка не устанавливает службы API/БД, не запускает миграции и не копирует базу.
Collector использует настроенный ServerUrl и устойчивый локальный outbox.

Генерируемые release, workspace, bin/obj, screenshots, диагностические файлы
и Python cache не входят в Git. Проверенные runtime-артефакты драйвера под
native/LU4Memory/artifacts/verified остаются версионированными.
Два последних ZIP и SHA256 находятся в release/packages; инструкции —
[DESKTOP_PACKAGES.md](DESKTOP_PACKAGES.md).

Серверный чат завершён. Итог переноса и проверки сайта сохранены в
docs/analysis/market-cycle, текущее состояние — в [RESUME.md](RESUME.md).
Повторные промежуточные checkpoint'ы с прежними PID и ожидаемыми деплоями
убраны из handoff-документов. Технические исследования игровых структур
и решений остаются в docs/analysis; это часть документации исходников.

Локальные browser evidence последней проверки находятся в ignored workspace.
Старые ZIP, publish staging, bin/obj и диагностические журналы являются
генерируемыми файлами. Они не нужны для сборки из исходников и не входят в Git.
