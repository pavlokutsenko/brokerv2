# PriceCheck Collector

Новый независимый Windows-коллектор для нескольких рынков и нескольких
игровых клиентов на одном компьютере.

Первый этап реализует оболочку роли **Брокер + радар**:

- несколько профилей рынков;
- папка клиента и роль для каждого профиля;
- запуск клиента из коллектора и автоматическая привязка нового `lu4.bin`;
- ручная привязка уже запущенного свободного процесса;
- обзор радара и счётчики трейдеров;
- прототипный импорт текущих JSON-диагностик для проверки интерфейса.

Роль **Сборщик цен** уже присутствует в модели профиля. Её runtime и серверная
очередь будут добавлены после проверки брокерного экрана.

## Сборка

```powershell
.\build.ps1
```

Настройки сохраняются в
`%LOCALAPPDATA%\PriceCheck\CollectorNext\profiles.json`.

Границы модулей и правила для будущего драйверного runtime описаны в
[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

Исходники, протокол, воспроизводимая сборка и проверенный бинарник нашего
драйвера находятся в [`native/LU4Memory`](native/LU4Memory). Драйвер теперь
является частью этого репозитория; старая исследовательская папка для его
сборки больше не нужна как источник истины.
