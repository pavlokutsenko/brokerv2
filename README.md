# PriceCheck Collector

Новый независимый Windows-коллектор для нескольких рынков и нескольких
игровых клиентов на одном компьютере.

Текущая сборка реализует единый профиль рынка:

- несколько профилей рынков;
- папка клиента и роль для каждого профиля;
- запуск клиента из коллектора и автоматическая привязка нового `lu4.bin`;
- ручная привязка уже запущенного свободного процесса;
- обзор радара и счётчики трейдеров;
- встроенный автономный брокерный worker для типов лавок 1, 3 и 8;
- локальную очередь точных проверок цен;
- ручной быстрый режим чтения лавок во время движения пользователя.

Автоматический маршрут остаётся экспериментальным. Текущий проверенный режим —
`manual-passby-shops.ps1`: пользователь ведёт персонажа, а worker без UI читает
лавки, попавшие в радиус. Текущее состояние и точные команды продолжения
записаны в [`docs/RESUME.md`](docs/RESUME.md).

## Сборка

```powershell
cd C:\broker
.\build.ps1
```

Готовая переносимая сборка появляется в `release\PriceCheckCollector`.
На компьютере коллектора не требуются установленный .NET, Python или
исследовательская папка `driver`: необходимые runtime, broker worker и
проверенный драйвер LU4Memory с загрузчиком уже находятся внутри поставки.
При запуске Windows запрашивает UAC для доступа к устройству драйвера. После
перезагрузки коллектор сам загружает LU4Memory и только затем открывает
интерфейс. Настройки сохраняются в
`profiles.json` рядом с `PriceCheck.Collector.exe`.

Границы модулей и правила для будущего драйверного runtime описаны в
[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

Исходники, протокол, воспроизводимая сборка и проверенный бинарник нашего
драйвера находятся в [`native/LU4Memory`](native/LU4Memory). Драйвер теперь
является частью этого репозитория; старая исследовательская папка для его
сборки больше не нужна как источник истины.
